# לוח רעיונות

קובץ ויזואלי אחד: `ideas/index.html` (פותחים בדפדפן).

## איך עובדים
1. **רעיון** – נשלח בצ'אט, גם במשפט אחד.
2. **תוכנית ראשונית** – Claude מוסיף כרטיס חדש למערך `IDEAS` עם:
   - תקציר ומטרה
   - שלבי ביצוע (מי אחראי על כל שלב)
   - טבלת אחריות
   - גבולות גזרה: בפנים / בחוץ / שאלות פתוחות
   - מוקאפ HTML להמחשה (ערכת `.phone` / `.desk` ומחלקות `m-*`)
   - סטטוס `feedback`
3. **פידבק** – כל הערה נרשמת ב-`feedback` עם תאריך, והתוכנית מתעדכנת (`updated`).
4. **החלטה** – הסטטוס עובר ל-`go` (ביצוע), `shelf` (גניזה) או נשאר בסבב.
5. **ביצוע** – רק אחרי `go` נכנסים לאפיון מפורט ולקוד, בתיקייה נפרדת.

## סטטוסים
`draft` טיוטה · `feedback` ממתין לפידבק · `decide` לקראת החלטה · `go` אושר לביצוע · `doing` בביצוע · `shelf` נגנז

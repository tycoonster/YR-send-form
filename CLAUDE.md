# CLAUDE.md

This repo currently holds an ideas board. When the user sends an idea, add it to `ideas/index.html`
following the workflow in `ideas/README.md` (Hebrew, RTL). Every idea gets: summary, goal, steps with owner,
responsibility table, scope (in / out / open questions), an illustrative HTML mockup, and a feedback log.
Do not start implementation until the idea's status is `go`.
